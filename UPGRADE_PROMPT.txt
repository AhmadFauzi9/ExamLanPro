HILANGKAN SEPENUHNYA FITUR "KUNCI SERVER" / "SERVER KEY"
karena mekanisme tersebut sudah tidak digunakan.

Yang harus dihapus:
- tombol Kunci Server
- input server key

- penyimpanan server key
- modal server key
- endpoint server key yang tidak lagi digunakan
- kode JavaScript yang hanya digunakan untuk server key
- teks UI yang masih menyebut server key

JANGAN menghapus autentikasi session guru.

Gunakan:
- PHP session/server session
- teacher login
- teacher logout
- password hash
- authorization berdasarkan session
- pengecekan session pada setiap endpoint guru

Pastikan setelah tombol "Kunci Server" dihapus, tidak ada fitur lain yang bergantung padanya.

==================================================
B. KEAMANAN SERVER
==================================================

Prioritas pertama adalah keamanan.

1. Jangan pernah mempercayai nilai berikut yang dikirim browser siswa:
   - nilai akhir
   - jumlah benar
   - jumlah salah
   - status lulus
   - kunci jawaban

2. Server harus menghitung hasil ujian.

Browser siswa cukup mengirim:
- quiz ID
- session ujian
- jawaban siswa

Server:
- mengambil soal
- mengambil kunci jawaban
- memvalidasi jawaban
- menghitung benar
- menghitung salah
- menghitung nilai
- menyimpan hasil

3. Kunci jawaban tidak boleh dikirim kepada siswa sebelum guru membuka fitur:
"Tampilkan Jawaban & Pembahasan".

4. Endpoint guru wajib memeriksa session guru.

5. Endpoint siswa tidak boleh dapat menjalankan:
- delete result
- reset result
- allow retake
- reveal answer
- edit quiz
- delete quiz
- import siswa
- import soal
- perubahan konfigurasi guru

6. Jangan menggunakan hidden input, localStorage, atau JavaScript sebagai satu-satunya mekanisme keamanan.

Keamanan harus berada di server.
