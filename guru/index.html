Import Soal Massal

Unggah butir soal via berkas Excel (.xlsx), Word (.doc), atau Teks (.txt)

Unduh Format Template Resmi

Gunakan format template resmi agar butir soal dapat dibaca dan dikonversi otomatis tanpa kesalahan tipe soal.

5 Bentuk Soal Standar Pemerintah (Kemendikbud/ANBK) yang Didukung:

• 1. MC (Pilihan Ganda Biasa): Satu pilihan benar (A, B, C, D, atau E).

• 2. COMPLEX (Pilihan Ganda Kompleks): Lebih dari satu pilihan benar (contoh kunci: 0,2 atau A,C).

• 3. MATCHING (Menjodohkan): Pasangan premis dan target (contoh: Monitor = Output atau 1=A, 2=B).

• 4. SHORT_ANSWER (Isian Singkat): Jawaban singkat kata/angka (variasi kunci dipisah tanda |).

• 5. ESSAY (Uraian / Esai): Pertanyaan esai bebas disertai pedoman/kunci jawaban.

Mendukung Import Gambar: Sisipkan/paste gambar langsung pada berkas Word (.docx/.doc) atau Excel (.xlsx) Anda. Sistem akan mengekstrak dan melampirkan gambar secara otomatis ke butir soal!

Panduan Jaringan Lokal (LAN)

Untuk menjalankan aplikasi kuis ini secara offline di Lab Komputer:

  1. Simpan file index.html dan api.php di folder XAMPP/Apache (htdocs/kuis).
  2. Cek Alamat IP Komputer Guru via Command Prompt CMD (ipconfig, misal: 192.168.1.100).
  3. Siswa membuka browser dari PC client masing-masing lalu mengakses alamat IP tersebut:
    http://192.168.1.100/kuis
